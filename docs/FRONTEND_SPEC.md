# Portfolio Tracking — 前端功能規格說明

> 本文件用於設計新版對外開放版本的參考資料。
> 描述現有私有版（內部）前端的完整功能、頁面結構、元件與資訊架構。

---

## 整體架構

**技術棧**：React + TypeScript + lightweight-charts + React Query + Tailwind  
**主題**：深色（Dark theme）  
**字型**：Plus Jakarta Sans（UI）、JetBrains Mono（數值/代碼）  
**API**：FastAPI (localhost:8000)

```
Shell（主容器）
├── Topbar（頂部欄，固定）
├── Tabbar（三個分頁）
└── Content（可滾動內容區）
    ├── Tab 0：持倉明細
    ├── Tab 1：資產配置
    └── Tab 2：資產走勢（預設開啟）
```

## 全局元件

### Topbar（頂部欄）

- **高度**：48px，固定置頂
- **左側**：藍色圓點 + "Portfolio" 品牌字樣
- **右側**：
  - 最後更新時間（格式：`YYYY-MM-DD HH:mm`）
  - LIVE 狀態指示燈（綠色閃點 + "LIVE" 字樣）
  - 美元/台幣即時匯率（格式：`1 USD = XX.X TWD`）

### Tabbar（分頁列）

三個分頁，點擊切換，活躍分頁底部有藍色 2px 邊框：
1. **持倉明細**
2. **資產配置**
3. **資產走勢**（預設開啟）

---

## Tab 0：持倉明細

**目的**：顯示所有投資帳戶的現有持倉，按平台分組。

### Section 1：統計卡片（4欄網格）

頂部四個摘要卡片，各有彩色上邊框：

| 卡片 | 顏色 | 顯示資訊 |
|------|------|---------|
| 總資產 | 藍色 | USD 總值 + NT$ 折合 |
| 幣圈 | 金黃 | 加密資產總值 + 佔比% |
| 美股 | 紅色 | 美股資產總值 + 佔比% |
| 台股 | 綠色 | 台股資產總值 + 佔比% |

### Section 2：持倉明細

標題："持倉明細"

每個平台為一張可折疊卡片，卡片標題顯示：
- 彩色縮寫方塊（2–4字元，背景色因平台而異）
- 平台名稱
- 該平台總資產（USD）
- 展開/折疊箭頭（帶旋轉動畫）

**折疊規則**：總資產 > $10,000 的平台預設展開。

---

#### 交易所平台（如 Bybit、OKX、MEXC）展開後

每個 Section（如「現貨」、「U本位期貨」）顯示一組表格：

**表格欄位**：
| 代碼 | 數量 | 單價 | 市值 |
|------|------|------|------|

- 代碼：以小方塊標籤顯示（等寬字體）
- 數量、單價、市值：右對齊，等寬字體
- Section 標頭行：深灰背景，顯示 Section 名稱 + Section 總值

---

#### 錢包平台（如 MetaMask、OKX Wallet）展開後

按地址分組，每個地址顯示：

**地址標頭**：
- 縮短地址（`0x1234…5678`，等寬字體）
- 鏈標籤（`ETHEREUM`、`POLYGON` 等，灰色方塊）
- 該地址總值（USD）

**下方表格**：同交易所格式，Section 可能為「持幣」、「NFT」等。

---

#### 互動行為

- 點擊平台卡片標題 → 展開/折疊
- 表格列 hover → 背景淡灰色
- 負值市值 → 紅色顯示

## Tab 1：資產配置

**目的**：視覺化資產配置比例、類別深鑽分析、歷史走勢、績效指標。

### Section 1：資產配置 + 迷你走勢圖（二欄並排）

#### 左欄：資產配置甜甜圈圖

**預設視圖**：
- 甜甜圈圖（SVG，圓心空心）
- 右側圖例，每個類別顯示：彩色圓點、類別名稱、佔比%
- 幣圈、美股、台股旁有 ↗ 符號，表示可點擊深鑽
- 底部提示文字："點選可展開"

**深鑽視圖**（點擊某類別後）：
- 標題變為："← 返回 [類別名] 持倉佔比"
- 甜甜圈圖更新為該類別前 8 大持倉品種的佔比
- 顏色以演算法生成（HSL，間距 47°，飽和度 60%，亮度 55%）
- 點擊"← 返回"回到預設視圖

#### 右欄：迷你資產走勢圖

- 使用 lightweight-charts，高度 180px
- 顯示整個投資組合的歷史走勢（總資產單線）
- 支援滾動和縮放
- 圖表下方顯示：最新總值 + 整體漲跌幅（正綠負紅）

---

### Section 2：績效指標

#### 時間窗口選擇器

按鈕組（單選）：`1W` `1M` `3M` `6M` `1Y` `2Y` `YTD` `all`  
預設：`YTD`

#### 指標卡片（2×2 格線）

各類別（總資產、幣圈、美股、台股）各一張卡片：

| 指標 | 說明 | 顯示格式 |
|------|------|---------|
| 報酬率 | 選定窗口的總回報 | `+8.23%`（正綠負紅） |
| Sharpe | 夏普比率 | `1.234`（純數字） |
| MDD | 最大回撤 | `-2.34%`（固定紅色） |

## Tab 2：資產走勢

**目的**：長期走勢圖、基準指數對比、各類別績效統計。

### Section 1：控制欄

**左側**：
- **模式切換**（Toggle）：`USD` | `報酬率 %`
  - USD 模式：顯示絕對資產值
  - 報酬率 % 模式：相對可見時間範圍起點的漲跌幅
- **投資組合系列芯片**（4 個）：`● 總資產` `● 幣圈` `● 美股` `● 台股`
  - 顏色各不同（藍/金/紅/綠）
  - 點擊切換該線的顯示/隱藏
  - 未啟用時半透明

**右側**（僅報酬率 % 模式有效）：
- **BENCHMARK 標籤**
- **基準芯片**（虛線樣式）：`┄ S&P 500` `┄ NASDAQ100` `┄ 費半` `┄ 0050` `┄ BTC`
  - 點擊切換可見性
  - 若當前是 USD 模式，點擊基準芯片會自動切換到報酬率 % 模式

---

### Section 2：主圖表

- **高度**：320px，全寬
- **圖表庫**：lightweight-charts
- **支援操作**：滾輪縮放、拖拽移動、兩指捏合
- **圖表內容**：
  - 投資組合線（實線，最多4條）
  - 基準指數線（虛線，最多3條）
  - 格線：水平 + 垂直
  - 十字光標（hover 時顯示）

#### 十字光標工具提示

hover 圖表時顯示浮動卡片，包含：
- 日期
- 各投資組合類別當日值（彩色圓點 + 值）
- 分隔線
- 前 4 大持倉品種及其佔比%
- "+N 更多" 提示

工具提示資料在 hover 停留 350ms 後以 API 非同步載入（快照查詢）。

---

### Section 3：時間窗口選擇器

- 標籤："收益計算區間"
- 按鈕組：`1W` `1M` `3M` `6M` `1Y` `2Y` `ALL`
- **注意**：只影響下方統計卡片的計算，不影響圖表的顯示範圍
- 預設：`1W`

---

### Section 4：統計卡片（4欄）

各類別各一張：

| 元素 | 說明 |
|------|------|
| 彩色點 + 類別名 | 視覺辨識 |
| 最新資產值（USD） | 大字號等寬字體 |
| 收益率 | 選定窗口內的總回報%，正綠負紅 |
| 窗口標籤 | 灰色小字，如 "1W" |

## API 端點總覽

| 端點 | 用途 | 使用分頁 |
|------|------|---------|
| `GET /api/portfolio/meta` | 最後更新時間、USD/TWD 匯率 | Topbar |
| `GET /api/holdings` | 所有持倉資料（按平台分組） | 持倉明細 |
| `GET /api/portfolio/allocation` | 資產類別分配比例 | 資產配置 |
| `GET /api/portfolio/allocation/{category}` | 特定類別的持倉深鑽 | 資產配置 |
| `GET /api/portfolio/metrics?window=` | 績效指標（報酬率/Sharpe/MDD） | 資產配置、資產走勢 |
| `GET /api/portfolio/history?window=all` | 完整歷史走勢資料 | 資產配置（迷你圖）、資產走勢 |
| `GET /api/benchmarks?tickers=...&start=` | 基準指數歷史資料 | 資產走勢 |
| `GET /api/portfolio/snapshot?date=` | 特定日期的持倉快照 | 資產走勢（hover tooltip） |

## 新版設計建議（給 Claude Design 的提示）

### 現有版本的限制（私有版）
- 純展示，無法新增/修改帳戶或資料來源
- 不支援用戶登入，無多用戶概念
- 所有連接設定都在後端環境變數中硬設

### 新版（對外開放版）需要的功能概念

**帳戶管理**
- 新增/刪除平台帳戶
- 支援多種連接方式：API Key、錢包地址、手動輸入
- 顯示每個帳戶的連接狀態（正常/失效/同步中）

**資料輸入**
- 手動新增持倉（for 不支援 API 的帳戶）
- 批次匯入（CSV、PDF 上傳）
- 設定定期自動同步排程

**用戶系統**
- 登入/註冊
- 資料加密儲存
- 可選擇公開分享或私有

**資產類型擴展**
- 房產、私募、其他資產類別
- 自訂類別標籤

**UI 改善機會**
- 行動裝置優化（目前無 RWD）
- 資產詳情頁（點擊品種查看歷史）
- 通知/警報設定（大幅波動通知）
- 深色/淺色主題切換
